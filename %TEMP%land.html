How it works

One setup. Every deposit after that is automatic.

Your server identifies the customer once. samedepo handles the address and deposit lifecycle from there.

  1. ​
    1
    Send a customer reference

    Make one GET request with a reference from your system, like cus_482.

  2. ​
    2
    Get permanent deposit addresses

    samedepo returns one permanent address for BTC, USDT, LTC, ETH, USDC and BNB.

  3. ​
    3
    Receive confirmed deposits

    We watch for deposits, wait for confirmations, credit your balance, and send your webhook.

Network infrastructure

Lower fees without more work.

Address formats, gas, and key custody are handled for you. Your integration stays the same.

Lower-cost Bitcoin transfers

SegWit

Bitcoin deposits use native SegWit addresses. They reduce transaction size and network fees without changing how customers send Bitcoin.

Automatic USDT gas handling

Gas

samedepo handles native gas — ETH, TRX, energy, and bandwidth — from treasury. Website owners and their customers don't need to fund deposit addresses with separate gas balances.

Isolated transaction signing

Custody

Private wallet keys never enter the website application. Deposits and withdrawals are signed by an isolated service through authenticated requests.

No. samedepo is built for websites where customers repeatedly add funds to an account balance. Register a customer once through the API and get permanent deposit addresses—no invoices, checkout sessions, or expiring payment links.
At launch, samedepo supports Bitcoin, USDT (TRC20), and USDT (ERC20). Each customer gets one permanent deposit address for each network. Other coins or tokens sent to those addresses aren’t credited.
samedepo watches each deposit address and waits until the transaction reaches the network’s confirmation requirement. It then deducts the deposit fee, credits your corresponding balance, and sends a webhook to your integration.
Creating an account and using the API is free. samedepo deducts a percentage fee from each confirmed deposit before crediting your balance. No hidden fees. Check the current fees and limits .
You set one withdrawal address for each supported network. Withdrawals send the full available balance, minus the blockchain network fee, once the configured minimum is reached. Limits and fees can change, so check the current values at https://samedepo.com/api-docs?tab=limits. Depending on your withdrawal mode, the request is sent immediately or reviewed before sending.
